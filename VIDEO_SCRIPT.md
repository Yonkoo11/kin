# <PROJECT> — demo video script

Target under 2 minutes. Shot list, not prose. Run `/demo-video` for the pipeline; house rules live
in the `demo-video` skill — no music, no synthetic end-cards, captions byte-match the audio, real
motion rather than static screenshots.

| # | seconds | on screen | said |
|---|---|---|---|
| 1 | 0:00–0:10 | the problem, concrete | <who loses what> |
| 2 | 0:10–0:25 | the app, real, live URL visible | <what this is, one sentence> |
| 3 | 0:25–1:15 | **the core action, unedited, in real time** | <narrate what is happening, not what it means> |
| 4 | 1:15–1:35 | the proof — tx, citation, log, measurement | <the number> |
| 5 | 1:35–1:50 | the sponsor's technology at its load-bearing step | <what breaks without it> |
| 6 | 1:50–2:00 | live URL on screen, held | <where to try it> |

Rules:
- The core action runs **once, unedited**. Cuts inside it read as a hidden failure.
- If the demo runs on a degraded tier, the banner is visible on screen and the narration says so.
- Show, do not narrate. If the screen already says it, do not say it.
